# Dzaba Build
Tools for building .NET monorepo code in cached and incremental way

## Features
Support for:
- [Nerdbank git versioning](https://github.com/dotnet/nerdbank.gitversioning)
- [Central Package Management](https://learn.microsoft.com/en-us/nuget/consume-packages/central-package-management)
- Air-gapped environments
- Custom cache storages
- .NET Framework and Core
- [Git sparse checkout](https://git-scm.com/docs/git-sparse-checkout)
- [Traversal MSBuild SDK](https://github.com/microsoft/MSBuildSdks/tree/main/src/Traversal)

CI system independent
